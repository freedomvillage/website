The optional wide-screen scene keeps the relevant existing illustration and contents location beside the prose through discovery, learning and faith at home. Native forward/backward scroll selects the matching decorative art as each chapter reaches the center of the usable reading area between contents and composer. The wide reader retains the original chapter breathing room and uses a larger, controlled prose measure; no blank spacer or minimum section height is inserted. It does not animate or add scroll distance, controls, content, assets or provider calls.

The stage requires at least 560px of content width, a viewport wider than 800px and at least 720px tall, plus 280px of usable space between the existing contents and composer. The scene height is also bounded by the shortest actual chapter so the last illustration can remain complete before release, without padding the reading. Otherwise the complete original static scenes remain. Reduced motion, no JavaScript and unsupported sticky positioning retain the full static reader. The stage releases before questions and closing actions.

Passive progress changes only decorative frame visibility and `aria-current` on the existing contents. It never moves focus, changes URL/hash/history or announces progress. Explicit native contents links keep their existing focus/hash behavior and select their matching scene until reading moves again; Back still restores the Family/Kids question context. Layout qualification updates on size changes, while passive scroll is coalesced into one animation-frame read and changes state only at chapter boundaries.

Cloud evidence uses actual wheel input and CDP-emulated touch scrolling forward and backward, separately from anchor jumps. Before captures use the exact PR-base CSS/JS with unchanged server markup and synthetic source records. Complete responsive pixels, keyboard navigation, reduced-motion/short-screen/no-script fallbacks, composer clearance and existing ranking/eligibility checks remain required.
