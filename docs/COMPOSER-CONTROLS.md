# Composer controls

The prompt area keeps its existing Appearance gear and explicit submit control.
It contains no social-link strip. Other site content and external destinations
are unaffected; this is a scoped correction to the composer.

The persistent role=status region stays empty at idle. Pending, error and ranked
result messages continue to use it. Its node is retained and not hidden; an empty
status uses zero flex basis so it does not create a redundant mobile row. The
privacy description remains associated with the textarea and becomes visible
when focused or when it contains a draft. No verbose idle sentence is restored.

The gear retains its accessible name, dialog association, keyboard operation,
settings behavior and focus return. The submit control, question handling and
explicit submission boundary are unchanged. Drafts are not sent by focusing the
composer or opening settings. Scene/logo/masonry, sticky bottom placement and the
existing measured-clearance observer remain. No new client JavaScript.
