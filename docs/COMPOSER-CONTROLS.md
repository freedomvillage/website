# Composer controls

The idle composer shows the five existing source-footer social links as icons,
followed by the icon-only Appearance gear and explicit submit control. Each link
keeps its authentic source href and icon outline, accessible name and 44px target.
The gear has no visible text; its accessible name, hover title, dialog association,
keyboard operation and focus return remain.

The persistent role=status region stays empty at idle. Pending, error and ranked
result feedback replaces the social strip while a status is present. The textarea
retains its privacy description, shown when focused or holding a draft. No verbose
idle helper sentence is restored. A question is sent only by explicit submission;
links and settings never send a draft.

The composer remains fixed at the bottom; measured clearance includes any wrapped
footer or status. Existing scene, logo, masonry and Jev eligibility/ranking remain.

The social links were first introduced by PR38. PR41 removed them after an earlier
“just the gear” direction was interpreted as removing the strip. The owner's latest
explicit correction restores the social links and removes only the visible gear
label. PR41's removal is superseded; it is not a standing product restriction.
